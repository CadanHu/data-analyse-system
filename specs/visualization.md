# 规格：可视化决策 (Visualization)

> 来源：`data-sys-docs/requirements/009-smart-visualization-and-metric-cards.md` + `010-advanced-visualization-and-auto-adaptation.md`
> 版本：v3.0

---

## 1. 图表类型

| 类型标识 | 图表名称 | 适用场景 |
|---------|--------|---------|
| `bar` | 柱状图 | 分类对比、排名 |
| `line` | 折线图 | 时间趋势、连续变化 |
| `pie` | 饼图 | 占比、构成分析 |
| `scatter` | 散点图 | 相关性分析 |
| `radar` | 雷达图 | 多维指标对比 |
| `funnel` | 漏斗图 | 转化率分析 |
| `card` | 指标卡片 | 单点数值汇总 |
| `table` | 表格 | 明细数据、多列展示 |

---

## 2. AI 决策规则

Agent 在 SQL 生成时，必须同时输出 `viz_config` 元数据，包含：
- `chart_type`：建议的图表类型
- `x`：X 轴字段名
- `y`：Y 轴字段名（可多个）
- `reasoning`：选择理由

**决策逻辑**（Agent 必须遵守）：

| 结果集特征 | 强制图表类型 |
|-----------|-----------|
| 单行单列（汇总数值） | `card` |
| 含时间列 + 数值列 | `line` |
| 分类列 + 数值列（≤20类） | `bar` |
| 占比语义（如"各类别百分比"）| `pie` |
| 多维指标（≥4个数值维度） | `radar` |
| 转化率 / 漏斗语义 | `funnel` |
| 其他多列 | `table` |

---

## 3. 指标卡片（Metric Card）规格

**触发条件**：SQL 执行结果恰好为 **1行 × 1列**

**展示规格**：
- 大字号数值居中展示
- 自动识别单位（如"元"、"%"、"个"）
- 数值超过 10000 自动格式化（如 `1.23万`、`12.3亿`）

---

## 4. 前端降级方案

若 AI 的 `viz_config` 缺失或字段名不匹配，前端执行启发式字段匹配：
1. 第一列含 `date`/`time`/`month`/`year` → 设为 X 轴，使用折线图
2. 第一列为字符串类型 → 设为 X 轴，使用柱状图
3. 数值列只有一列且行数 = 1 → 使用指标卡片
4. 均不匹配 → 降级为表格

---

## 5. 历史消息回看

- 点击历史消息中的图表按钮，必须能完整复现当时的可视化画面
- `chart_cfg` 存入 `messages` 表，不依赖前端 Store 恢复
